## 🚀 Projects

Two real systems, designed and developed independently. Each repository has its own README with architecture and setup instructions.

### GEA — Events & Announcements Platform

A web platform, mobile app and REST API for managing events, announcements, spaces and reservations at Universidad Libre, Cúcuta Campus. Built during my time as Software Developer there (Jan – Jun 2026).

| Part | Stack | Repository |
|---|---|---|
| Backend | Java · Spring Boot · Spring Security · JWT · MySQL | [Backend_gea](https://github.com/x6Darck/Backend_gea) |
| Web | React · Vite · Axios · Shadcn/UI | [Front_gea](https://github.com/x6Darck/Front_gea) |
| Mobile | Flutter · Dart · Riverpod | [Movil_gea](https://github.com/x6Darck/Movil_gea) |

### FarmStock — Offline Inventory System

An inventory system for the tools and equipment of a SENA farm in El Zulia, designed to work without a stable internet connection. Includes QR codes, PDF reports and email notifications.

| Part | Stack | Repository |
|---|---|---|
| Backend | Java · Spring Boot · MySQL | [FarmStock_Backend](https://github.com/x6Darck/FarmStock_Backend) |
| Desktop | Electron · JavaScript | [FarmStock_Front](https://github.com/x6Darck/FarmStock_Front) |
